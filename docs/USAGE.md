# 安装与使用

## 前提

- 已验证的组合：Sony X9500H / Android 9 / RMF-TX910C。
- 遥控器通过蓝牙配对。保留蓝牙连接才能继续免对准操作与语音功能。
- 电视开启网络 ADB 调试，端口为 5555。菜单名称随固件而变；本项目不提供强制开启或绕过认证的方法。
- 安装已签名 APK，并核对发布附带的 SHA-256 校验值。`-unsigned.apk` 不能直接安装。

## 使用电脑安装

安装 Android 官方 Platform Tools 后，在终端设置电视地址和 APK 路径：

```sh
TV_ADDRESS='电视的局域网地址'
APK_PATH='Sony-Keyfix-1.0.0.apk'
adb connect "$TV_ADDRESS:5555"
adb -s "$TV_ADDRESS:5555" install -r "$APK_PATH"
```

地址占位文字需要替换。若电脑的 ADB 默认端口 5037 已被占用，可在每条 `adb` 命令后统一加 `-P 5038`；无需终止其他程序的 ADB 服务。

`install -r` 升级同包名、同签名的版本并保留数据。项目沿用包名 `local.sony.keyfix`。签名不同会导致升级被拒绝；不要直接卸载已有版本来绕过问题，否则设置和本机 ADB 密钥都会丢失。

## 首次运行

1. 在电视应用列表打开 **Sony Keyfix**，选择「启动修复」。
2. 在电视调试授权框中勾选「始终允许」，选择允许。应用与电脑的 ADB 身份不同，可能需要单独授权。
3. 如需开机恢复，勾选「电视重启后自动恢复」。新安装默认不勾选，升级保留原选项。
4. 测试输入源与齿轮；进入支持菜单的应用后再测试选项与三横线。
5. 电脑可执行 `adb disconnect "$TV_ADDRESS:5555"` 后退出，后续运行不依赖电脑。

## 状态与恢复

| 状态 | 处理 |
| --- | --- |
| 正在运行 | 四个映射已启用，可关闭此界面 |
| 等待蓝牙遥控器连接 | 短按任意键唤醒；确认遥控器已蓝牙配对 |
| 正在连接 / 重新连接 | 检查调试开关与授权；应用约每 5 秒重试 |
| 系统不兼容 | 检查 Android 版本与用户空间，参见兼容文档 |
| 已停止 | 选择「启动修复」继续 |

不要同时运行其他按键修复脚本，否则同一按键可能触发两次。注入较慢时，应用最多保留 4 个待处理动作，多余动作会丢弃，避免稍后连续误触。

「停止修复」会保存关闭状态，重启与升级后也不会自动开启。只取消开机恢复，不会停止当前服务。系统的「强行停止」可能阻止开机广播，需要重新打开应用并启动。

## 卸载

电视设置 → 应用 → Sony Keyfix → 卸载。应用私钥、设置与服务随应用移除；电视可能保留已授权的公钥记录。不要为了卸载本应用而清除所有 ADB 授权，这会影响其他已授权设备。清除应用数据后重新使用，需要再次授权。
