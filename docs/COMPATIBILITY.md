## 基线安装的人工验证

- 临时测试中，输入源、齿轮、选项、三横线均由用户确认有效。
- 应用独立运行且电脑 ADB 已断开时，用户确认四键与语音正常。
- 正常重启后应用自动恢复，输入节点从 event2 变为 event3，服务跟随新节点。
- 重启后再次断开电脑，用户确认输入源与齿轮仍有效；菜单两键未在这次重启后单独复测。

## 1.0.0 发布构建

- 本地通过四键解析、79 种数据分片、重复抑制、普通按键不映射、SYN_DROPPED 恢复测试。
- 通过严格设备路径识别、启停/开机/升级策略、shell 失败检测测试。
- 通过 ADB 长度与队列边界、校验、UTF-8 地址和关闭原因测试；60 轮快速 OPEN/WRTE/CLSE 测试未丢失尾包或发生等待死锁。
- APK 已通过 v2/v3 签名与对齐校验，使用原安装签名覆盖升级成功。
- 将公开源码 ZIP 解压到独立目录后重新构建，生成的 classes.dex、资源、Manifest 和许可文件与已签名 APK 完全一致。此项验证的是内容一致性，不宣称整个 APK 逐字节可复现。
- 升级后前台服务自动恢复，原开机恢复选项与 ADB 授权保留，无需重新授权；界面显示四键映射运行中。
- 1.0.0 安装后，用户再次确认四个按键与语音均正常。这次复测时电脑 ADB 仍连接用于检查界面；电脑断开运行和正常重启的独立实机证据来自上述基线安装。

## 尚未验证

连续多天、深度待机、断电冷启动、全部固件版本、其他电视与遥控器、现代 Android 无线调试配对均不在已验证范围。发布版使用正常产品文案，不代表已经完成这些耐久或兼容性测试。

拓展设备前应分别验证输入事件宽度、HID 身份、扫描码、系统动作以及 shell 权限，不应直接移除兼容性限制。
