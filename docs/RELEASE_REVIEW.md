# 1.0.0 发布评估

## 结论

已整理为可公开的源码项目，已构建、签名并在既有 X9500H 上覆盖升级。用户确认新版四键和语音正常。适合按已记录的设备范围发布；不应宣传为全型号通用或长期耐久认证。

## 本次处理

| 检查项 | 处理结果 |
| --- | --- |
| 产品文案 | 清理开发阶段标签、过期重启提示和容易误解的默认状态描述；主页面显示功能与状态 |
| 电视操作 | 使用密度无关尺寸、可滚动容器、方向键可达按钮；帮助、关于和许可证独立展示 |
| 语言 | 中英文资源完整对应，版本由安装包元数据读取 |
| 已有安装 | 保持包名、偏好键、签名和本机 ADB 密钥；覆盖升级保留设置 |
| 恢复行为 | 开机按用户选项恢复；升级按此前启停状态恢复；停止状态不会被自动启动覆盖 |
| 输入解析 | 固定四键白名单、严格设备路径、重复抑制与丢帧恢复 |
| 连接稳定性 | 修复旧连接影响新连接的风险；限制队列、包长与输出大小；识别 shell 中断 |
| 构建 | 移除个人路径与默认签名密码；离线脚本、显式签名与签名验证；解压源码独立重建内容一致 |
| 开源材料 | 双语 README、安装与构建、架构、兼容、贡献、安全、更新记录和问题模板 |
| 许可 | MIT 项目代码，保留 AdbLib BSD-3-Clause 原文、固定版本和修改记录；APK 内可查看 |

| GitHub CI | 固定 action 提交、只读权限、无签名密钥、无自动发布步骤 |

## 保留的边界

- Android 9 / 32 位 ARM 是实现约束，不是仅为了提示而写在文档里的标签。
- 需要持续启用电视 ADB，连接权限相当于 shell；没有 Root，不代表不需要授权。
- 主界面不响应菜单是应用行为，不应改成其他功能来掩盖。
- 深度待机、冷启动、多日稳定性、其他固件与其他机型仍待验证。
- 发布构建已在本机验证，GitHub 托管 CI 需要仓库上传后的首次运行确认。
- 当前构建不宣称二进制可复现、第三方安全审计或应用商店合规认证。

源码可以上传到新仓库，安装包可作为手动 Release 附件。私有签名密钥应另行备份并继续用于升级，不应放入 Git 历史。
